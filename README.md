# HTML Resume

A simple resume webpage created using basic HTML tags and elements.

## Features

- Personal details
- Education details
- Skills list
- Hobbies
- Images
- Marquee messages
- Place and signature section

## Concepts Used

- HTML headings and paragraphs
- `<center>` and `<u>`
- `<marquee>`
- Images using `<img>`
- Unordered lists
- Basic text formatting
